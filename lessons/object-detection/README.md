# 객체 탐지 · 딥러닝

밤길 교차로에서 자율주행차가 한 프레임의 영상 안에서 보행자 두 명, 앞차 한 대, 정지선 하나를 동시에 찾아내고 각각의 위치를 사각형 박스로 표시해야 한다고 하자. 사람은 한눈에 가능한 일이지만, 컴퓨터에게는 수십만 개 픽셀 중 어느 영역이 "보행자"라는 범주에 속하는지를 수치적으로 판단해야 하는 어려운 문제다. 앞서 배운 카메라·비전(cam-vision)에서 에지나 색상 같은 저수준 특징을 손으로 설계해 찾아냈다면, 객체 탐지·딥러닝 단계에서는 이 특징 추출 자체를 데이터로부터 학습한 신경망에 맡긴다.

딥러닝 기반 인지는 2012년 이후 영상 인식 전반을 바꾸어 놓았고, 자율주행에서도 차선·차량·보행자·신호등 인식의 표준 방법이 되었다. 이 레슨에서는 객체 탐지, 분할, 추적이라는 세 가지 핵심 과업과 이를 평가하는 지표를 다룬다.

## 학습 목표

- 바운딩 박스 기반 객체 탐지의 기본 구조(앵커, 분류·회귀 헤드)를 설명할 수 있다.
- 2단계 탐지기와 1단계 탐지기의 구조적 차이를 비교할 수 있다.
- 시맨틱 분할과 인스턴스 분할의 차이를 구분할 수 있다.
- IoU, mAP 등 탐지 성능 지표의 의미를 계산 원리로 이해한다.
- 프레임 간 객체를 연결하는 추적의 필요성을 설명할 수 있다.

## 객체 탐지: 2단계 방식과 1단계 방식

객체 탐지(object detection)는 영상에서 물체의 위치(바운딩 박스)와 종류(클래스)를 동시에 예측하는 과업이다. R-CNN 계열로 대표되는 2단계(two-stage) 방식은 먼저 물체가 있을 법한 후보 영역을 제안(region proposal)한 뒤, 각 후보를 분류·정교화하는 두 단계를 거친다. 정확도는 높지만 연산량이 많아 실시간성이 떨어진다.

반면 YOLO, SSD 같은 1단계(one-stage) 방식은 영상 전체를 격자(grid)로 나누고 각 격자 셀에서 바로 바운딩 박스와 클래스를 동시에 예측한다. 후보 제안 단계를 생략하는 대신 속도가 빨라서, 매 프레임을 30 fps 이상으로 처리해야 하는 자율주행 실시간 인지에 널리 쓰인다. 두 방식 모두 핵심은 "이 영역에 물체가 있는가(objectness)"와 "있다면 어떤 클래스인가"를 동시에 학습하는 것이다.

## 분할: 픽셀 단위로 세상을 나누기

바운딩 박스는 물체를 사각형으로만 표시하므로 차선처럼 가늘고 긴 대상이나 도로 경계처럼 불규칙한 형태를 표현하기 어렵다. 이때 쓰는 것이 분할(segmentation)이다. 시맨틱 분할(semantic segmentation)은 영상의 모든 픽셀에 "도로", "차선", "하늘" 같은 클래스 레이블을 붙이지만 같은 클래스에 속한 개체들을 구분하지는 않는다. 인스턴스 분할(instance segmentation)은 여기서 한 걸음 더 나가 "차량 A"와 "차량 B"를 픽셀 단위로 서로 다른 개체로 구분한다. 자율주행에서는 자유 공간(주행 가능 영역)을 픽셀 단위로 파악하기 위해 시맨틱 분할이, 서로 겹쳐 있는 보행자 여러 명을 구분하기 위해 인스턴스 분할이 활용된다.

## 추적: 프레임을 넘어 물체를 이어 붙이기

탐지는 한 프레임 안의 정적인 결과만 준다. 하지만 자율주행은 "저 보행자가 1초 전보다 어느 방향으로 얼마나 빠르게 움직였는가"를 알아야 충돌을 예측할 수 있다. 이를 위해 추적(tracking)은 매 프레임의 탐지 결과를 이전 프레임의 결과와 매칭시켜 같은 물체에 일관된 ID를 부여한다. 위치 예측에는 칼만 필터 계열 기법이 흔히 쓰이고, 외형이 비슷한 물체를 구분하기 위해 재식별(Re-ID) 특징을 함께 사용하기도 한다.

## 성능을 재는 척도: IoU와 mAP

탐지 품질은 예측 박스와 실제 정답 박스(ground truth)가 얼마나 겹치는지를 나타내는 IoU(Intersection over Union)로 측정한다.

$$
\text{IoU} = \frac{\text{겹치는 영역}}{\text{합친 영역}}
$$

보통 IoU가 0.5 이상이면 올바른 탐지로 간주한다. 여러 클래스, 여러 신뢰도 임계값에 대한 정밀도-재현율 곡선을 평균한 지표가 mAP(mean Average Precision)이며, 서로 다른 탐지 모델의 성능을 비교하는 표준 척도로 쓰인다.

## 정리

객체 탐지·딥러닝은 영상 속 물체의 위치와 종류를 바운딩 박스로 찾는 탐지, 픽셀 단위로 영역을 나누는 분할, 시간에 따라 같은 물체를 연결하는 추적이라는 세 과업으로 구성된다. 2단계·1단계 탐지기의 속도-정확도 트레이드오프와 IoU·mAP 같은 평가 지표를 이해하면, 실제 자율주행 인지 스택에서 어떤 모델을 왜 선택하는지를 판단할 수 있다.
