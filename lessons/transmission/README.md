# 변속기 (MT/AT)

가솔린 엔진은 보통 800 rpm 근처에서 아이들링하고, 최대 토크는 3000 ~ 4500 rpm 부근에서 나온다. 그런데 자동차가 정지 상태에서 출발할 때 바퀴는 0 rpm이다. 엔진이 가장 힘을 잘 내는 회전수와 바퀴가 실제로 필요로 하는 회전수·토크는 전혀 다르다. 이 간극을 메워주는 장치가 바로 변속기(transmission)이다. 자전거의 다단 변속기를 떠올리면 쉬운데, 가파른 언덕에서는 저단(큰 기어비)으로 페달을 적게 밀어도 큰 힘을 내고, 평지에서 빠르게 달릴 때는 고단(작은 기어비)으로 바꿔 적은 회전으로도 멀리 가게 한다. 앞서 배운 동역학 기초 위에서, 변속기는 결국 엔진의 토크-회전수 특성과 주행에 필요한 힘-속도 특성을 기어비로 매칭시켜주는 장치라고 이해하면 된다.

## 학습 목표

- 기어비가 토크와 회전수를 어떻게 맞바꾸는지 수식으로 이해한다.
- 수동변속기(MT)의 클러치와 싱크로메시 동작 원리를 설명할 수 있다.
- 자동변속기(AT)의 토크컨버터와 유성기어 세트의 역할을 이해한다.
- 변속단 수가 가속성능과 연비에 어떤 영향을 주는지 설명할 수 있다.

## 기어비: 토크와 회전수의 트레이드오프

두 기어가 맞물려 돌아갈 때, 입력 토크 $T_{in}$과 회전수 $\omega_{in}$이 기어비 $i$를 거치면 다음과 같이 변한다(마찰 손실을 무시한 이상적인 경우).

$$T_{out} = i \cdot T_{in}, \quad \omega_{out} = \frac{\omega_{in}}{i}$$

입력과 출력의 동력 $P = T \cdot \omega$는 보존되므로, 기어비를 키우면 회전수는 줄고 토크는 그만큼 커진다. 예를 들어 1단 기어비가 3.5라면, 엔진이 200 N·m를 낼 때 변속기 출구에서는 약 700 N·m로 커지지만 회전수는 1/3.5로 줄어든다. 출발할 때처럼 큰 힘이 필요하면 큰 기어비를, 고속 정속 주행처럼 회전수를 낮춰 연비를 아끼고 싶을 때는 작은 기어비를 쓴다. 실제 승용차용 변속기는 보통 1단 3 ~ 4, 최고단 0.6 ~ 0.8 정도의 기어비를 가진 여러 단을 두어 이 범위를 나눠 쓴다.

## 수동변속기(MT): 클러치와 싱크로메시

MT는 운전자가 직접 클러치 페달로 엔진과 변속기 입력축을 분리한 뒤, 변속레버로 원하는 기어를 선택하고 다시 클러치를 연결하는 구조다. 기어 자체는 항상 맞물려 돌고 있지만(상시 맞물림식), 실제로 축에 동력을 전달하는 것은 싱크로메시(synchro-mesh) 허브다. 변속 시 기어와 출력축의 회전수가 다르면 이빨이 충돌해 소리가 나거나 손상되므로, 싱크로나이저 링이 마찰력으로 두 부품의 회전수를 먼저 맞춘 뒤 도그 클러치가 맞물리도록 해준다. 이 과정이 있어 운전자가 별도의 더블클러치 조작 없이도 부드럽게 기어를 바꿀 수 있다.

## 자동변속기(AT): 토크컨버터와 유성기어

AT는 클러치 페달 없이 유체와 유성기어의 조합으로 변속을 자동화한다. 토크컨버터는 엔진과 변속기 사이에서 오일을 매개로 동력을 전달하는 유체 커플링인데, 일반적인 유체 커플링과 달리 스테이터(stator)가 오일 흐름 방향을 바꿔주어 정지 상태나 저속에서 토크를 1.5 ~ 2배 이상 증폭시킨다(토크 멀티플리케이션). 어느 정도 속도가 오르면 입력과 출력의 회전수 차이가 줄어들므로, 락업 클러치(lock-up clutch)가 기계적으로 맞물려 슬립 손실을 없애고 효율을 높인다.

변속 자체는 유성기어 세트(선기어-유성기어-링기어)로 이뤄진다. 선기어, 유성기어 캐리어, 링기어 중 하나를 고정하거나 입력으로 쓰고 나머지를 출력으로 삼으면 여러 기어비를 만들 수 있다. 여러 개의 유성기어 세트를 클러치와 브레이크로 조합하는 심슨(Simpson) 기어트레인이나 라비뇨(Ravigneaux) 기어트레인을 쓰면 6단, 8단, 10단처럼 많은 단수를 비교적 작은 패키지 안에 구현할 수 있다. 단수가 많아질수록 각 단의 기어비 간격이 좁아져 엔진을 항상 효율이 좋은 회전수 근처에 머물게 할 수 있어, 가속성능과 연비를 동시에 개선하는 경향이 있다.

## 정리

변속기는 엔진의 토크-회전수 특성을 주행 상황에 맞게 변환해주는 핵심 구동계 부품이다. MT는 클러치와 싱크로메시로 운전자가 직접 기어비를 바꾸고, AT는 토크컨버터로 부드럽게 동력을 전달하면서 유성기어 세트의 조합으로 자동 변속을 구현한다. 이 변속 원리는 다음에 배우는 DCT·CVT, 그리고 차동기어·AWD로 이어지는 구동계 전체를 이해하는 토대가 된다.
