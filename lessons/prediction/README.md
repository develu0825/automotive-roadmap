# 거동 예측

횡단보도 앞에 서 있는 보행자를 발견했다고 해보자. 이 사람은 그냥 서 있는 걸까, 아니면 곧 길을 건너려는 걸까? 옆 차선에서 깜빡이도 없이 속도를 줄이는 차는 내 차선으로 끼어들려는 걸까, 그냥 서행하는 걸까? 사람 운전자는 이런 질문에 경험적으로 답하며 미리 대비한다. 자율주행차도 마찬가지로, 현재 보이는 위치와 속도만으로는 부족하고 "다음 몇 초 동안 저 객체가 어떻게 움직일 것인가"를 예측해야 안전한 판단을 내릴 수 있다. 이 역할을 맡는 모듈이 거동 예측(prediction)이다.

거동 예측은 앞서 배운 객체 탐지(object detection)가 넘겨주는 "지금 이 순간의 위치·속도·분류 정보"를 입력으로 받아, 그 객체의 미래 경로에 대한 확률적 추정을 만들어낸다. 그리고 이 예측 결과는 다시 행동 결정(behavior) 모듈로 전달되어 "양보할지, 진행할지"와 같은 판단의 핵심 근거가 된다. 즉 예측은 인지와 판단을 잇는 다리 역할을 하며, 자율주행 스택에서 가장 불확실성이 큰 동시에 안전에 직결되는 모듈 중 하나다.

## 학습 목표

- 거동 예측이 객체 탐지와 행동 결정 사이에서 수행하는 역할과 입출력을 설명할 수 있다.
- 물리 기반 예측과 데이터 기반(학습) 예측의 차이와 각각의 한계를 이해한다.
- 멀티모달(multi-modal) 예측이 왜 필요한지, 그리고 예측 결과가 어떻게 확률분포 형태로 표현되는지 설명할 수 있다.
- 예측의 불확실성이 행동 결정과 경로 생성에 어떻게 반영되는지 이해한다.

## 예측의 입력과 출력

거동 예측 모듈의 입력은 보통 다음과 같다.

- 대상 객체의 과거 궤적(위치·속도·가속도의 시계열, 보통 최근 1 ~ 3초 분량)
- 객체의 분류 정보(차량, 보행자, 자전거 등 — 분류에 따라 움직임의 패턴이 크게 다르다)
- 주변 환경 정보(차선 구조, 신호, 횡단보도 위치, 다른 객체와의 관계)

출력은 단일한 미래 위치가 아니라, 보통 다음 몇 초(예: 3 ~ 8초) 동안의 미래 궤적에 대한 확률분포다. 예를 들어 "이 차량이 70%의 확률로 직진하고, 30%의 확률로 좌회전한다"처럼 여러 가능성(멀티모달, multi-modal)을 동시에 표현하는 것이 중요하다. 단 하나의 경로만 예측하면 실제로 다른 행동을 할 경우 자율주행차가 전혀 대비하지 못하는 상황이 생기기 때문이다.

## 물리 기반 예측과 데이터 기반 예측

예측 방법은 크게 두 갈래로 나뉜다.

1. 물리 기반(physics-based) 예측: 등속도 모델(Constant Velocity), 등가속도 모델, 칼만 필터(Kalman Filter) 기반 외삽처럼 운동 방정식을 이용해 짧은 시간 뒤의 위치를 추정한다. 계산이 가볍고 1초 이내의 짧은 예측에는 비교적 정확하지만, 사람이나 차량의 "의도"는 반영하지 못해 교차로처럼 방향이 급격히 바뀌는 상황에서는 금방 부정확해진다.
2. 데이터 기반(data-driven) 예측: 과거 주행 데이터를 학습한 신경망 모델(RNN, LSTM, Transformer, 그래프 신경망 등)을 이용해 도로 구조와 주변 객체 간의 상호작용까지 고려한 예측을 만든다. 예를 들어 그래프 신경망은 각 객체를 노드로, 객체 간 상호작용을 엣지로 표현해 "내가 끼어들면 뒤차가 속도를 줄일 것이다"와 같은 상호작용을 학습한다. 이런 방식은 더 긴 시간(수 초 이상)의 예측에서 물리 기반 모델보다 훨씬 현실적인 결과를 내지만, 학습 데이터에 없던 드문 상황(long-tail)에서는 성능이 급격히 떨어질 수 있다는 한계가 있다.

실제 양산 시스템에서는 짧은 시간 구간에는 물리 기반 모델을, 조금 더 긴 시간 구간에는 데이터 기반 모델을 결합하거나, 두 방식을 앙상블로 사용하는 경우가 많다.

## 불확실성과 행동 결정으로의 전달

예측이 완벽할 수 없다는 사실을 자율주행 시스템은 설계 단계부터 받아들여야 한다. 그래서 예측 결과는 보통 하나의 경로가 아니라 "경로 후보들과 각각의 확률", 또는 시간에 따라 넓어지는 불확실성 영역(uncertainty cone)으로 표현된다. 예를 들어 1초 뒤에는 ±0.5 m, 5초 뒤에는 ±3 m 처럼 시간이 지날수록 예측 오차 범위가 커지는 식이다. 행동 결정 모듈은 이 불확실성을 고려해, 확률이 낮더라도 위험한 시나리오(예: 보행자가 갑자기 차도로 들어설 가능성)에는 충분한 안전 여유(safety margin)를 두도록 설계된다. 이처럼 예측과 행동 결정은 분리된 모듈이면서도, 예측의 불확실성 표현 방식이 행동 결정의 안전성을 좌우하는 긴밀한 관계에 있다.

## 정리

거동 예측은 객체 탐지가 알려준 현재 상태를 바탕으로 주변 차량과 보행자의 미래 움직임을 추정해, 행동 결정이 안전한 판단을 내릴 수 있도록 돕는 모듈이다. 물리 기반 예측은 짧은 시간에 가볍고 안정적이지만 의도를 반영하지 못하고, 데이터 기반 예측은 상호작용과 의도를 더 잘 반영하지만 드문 상황에서 취약하다는 한계가 있다. 실제 시스템은 단일 경로가 아닌 멀티모달 확률분포로 예측 결과를 표현하고, 그 불확실성을 행동 결정과 경로 생성 단계에서 안전 여유로 반영한다.
