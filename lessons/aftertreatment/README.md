# 후처리 (촉매·DPF·SCR)

디젤차 주유구 옆에 파란 뚜껑의 작은 주입구가 하나 더 있는 것을 본 적이 있을 것이다. 거기에 넣는 것이 요소수(AdBlue)이고, 이는 질소산화물을 줄이기 위한 SCR 시스템의 재료다. 엔진 안에서 연소를 아무리 잘 설계해도 배출가스를 규제 기준까지 낮추기는 어렵다는 것을 앞 레슨에서 확인했다. 그래서 배기가스가 엔진을 떠난 뒤, 대기로 나가기 전에 한 번 더 유해물질을 처리하는 장치들이 필요하다.

앞서 배운 배기 규제 대응 위에서, 이번 레슨은 가솔린차의 삼원촉매(TWC), 디젤차의 매연필터(DPF), 그리고 질소산화물을 줄이는 요소수 SCR 시스템을 다룬다.

## 학습 목표

- 삼원촉매(TWC)가 CO·HC·NOx를 동시에 처리하는 세 가지 반응과 공연비 윈도우의 의미를 설명할 수 있다.
- DPF의 매연 포집 구조와 재생(regeneration) 원리를 설명할 수 있다.
- SCR에서 요소수가 분해되어 NOx를 환원하는 과정을 설명할 수 있다.
- 디젤차와 가솔린차의 후처리 시스템 구성 차이를 이해한다.

## 삼원촉매(TWC): 세 가지를 한 번에

삼원촉매(TWC, Three-Way Catalyst)는 백금·팔라듐·로듐 같은 귀금속을 코팅한 벌집 모양 구조물로, 배기가스가 이를 통과하며 세 가지 반응이 동시에 일어난다.

- CO를 CO2로 산화시킨다.
- 미연소 HC를 CO2와 물(H2O)로 산화시킨다.
- NOx를 질소(N2)로 환원시킨다.

흥미로운 점은 산화 반응(CO, HC 처리)과 환원 반응(NOx 처리)이 정반대 성격을 가진다는 것이다. 산화에는 산소가 남아 있어야 유리하고, 환원에는 산소가 부족해야 유리하다. 그런데 삼원촉매는 공연비가 이론 공연비(람다 = 1)에 아주 가까운 좁은 범위, 이른바 공연비 윈도우(catalyst window) 안에서만 세 가지 반응을 동시에 높은 효율로 처리할 수 있다. 이 때문에 가솔린 엔진은 배기관에 설치된 산소센서(람다센서)로 실제 공연비를 실시간 측정하고, ECU가 연료 분사량을 미세 조정해 람다를 1 부근으로 계속 되돌리는 피드백 제어를 수행한다. 디젤 엔진은 항상 공기 과잉(희박) 상태로 운전되기 때문에 삼원촉매의 환원 반응이 제대로 작동하지 않아, 전혀 다른 방식의 NOx 저감 장치가 필요하다.

## DPF: 매연을 걸러내고 태워버린다

DPF(Diesel Particulate Filter, 매연필터)는 세라믹 재질의 벌집 구조 안에서 통로를 번갈아 막아, 배기가스가 벽을 통과하도록 강제하는 필터다. 가스는 다공성 벽을 빠져나가지만, 그을음 입자(PM)는 벽에 걸러져 쌓인다.

입자가 계속 쌓이면 배기 저항이 커지고 성능이 떨어지므로, 주기적으로 쌓인 입자를 태워 없애는 재생(regeneration) 과정이 필요하다. 재생은 크게 두 가지로 나뉜다.

- 수동 재생(passive regeneration): 고속 주행 등으로 배기 온도가 충분히 높아질 때(대략 섭씨 350도 이상) 자연스럽게 그을음이 산화되어 없어지는 방식이다.
- 능동 재생(active regeneration): 평소 저속·단거리 위주로만 주행해 배기 온도가 충분히 오르지 않으면, ECU가 의도적으로 추가 연료를 분사하거나 배기 쪽 촉매(DOC, 디젤산화촉매)를 이용해 배기 온도를 섭씨 600도 안팎까지 끌어올려 강제로 그을음을 태운다.

단거리 저속 주행만 반복하면 재생이 제대로 이루어지지 않아 DPF가 막히는 문제가 생길 수 있어, 가끔 고속 주행을 포함시키는 것이 DPF 수명 관리에 도움이 된다고 알려져 있다.

## SCR: 요소수로 질소산화물을 분해한다

SCR(Selective Catalytic Reduction, 선택적 촉매환원)은 요소수(디젤 배기유체, DEF 또는 AdBlue)를 배기가스에 분사해 NOx를 질소와 물로 바꾸는 시스템이다. 요소수는 요소(urea)를 물에 녹인 용액으로, 뜨거운 배기가스 속에 분사되면 먼저 가수분해되어 암모니아(NH3)를 만든다. 이 암모니아가 SCR 촉매 위에서 배기가스 중의 NOx와 반응해 무해한 질소와 물로 바뀐다. 대략적인 반응을 정리하면 다음과 같다.

$$4NH_3 + 4NO + O_2 \rightarrow 4N_2 + 6H_2O$$

SCR은 디젤 엔진의 희박 연소 조건에서도 효과적으로 NOx를 줄일 수 있다는 점에서, 삼원촉매가 처리하지 못하는 영역을 보완한다. 다만 요소수를 정기적으로 보충해야 하고, 요소수가 부족하면 경고등이 뜨고 결국 시동 성능이 제한되기도 한다는 점이 특징이다.

## 가솔린과 디젤의 후처리 시스템 비교

가솔린 엔진은 일반적으로 삼원촉매 하나로 CO·HC·NOx를 동시에 처리하고, 필요에 따라 가솔린 입자상물질필터(GPF, Gasoline Particulate Filter)를 추가한다. 반면 디젤 엔진은 여러 장치를 순서대로 배치하는 경우가 많다. 먼저 디젤산화촉매(DOC)가 CO와 HC를 산화시키고 재생용 열을 공급하며, 이어서 DPF가 입자상물질을 걸러내고, 마지막으로 SCR이 NOx를 환원시키는 구조다. 이처럼 디젤 후처리 시스템이 더 복잡한 이유는, 희박 연소 특성상 삼원촉매 하나로는 NOx와 PM을 동시에 처리할 수 없기 때문이다.

## 정리

삼원촉매는 공연비가 이론 공연비에 가까운 좁은 구간에서 CO·HC·NOx를 동시에 처리하는 가솔린 엔진의 핵심 후처리 장치이고, DPF는 그을음 입자를 물리적으로 걸러낸 뒤 주기적으로 태워 없애는 재생 과정을 거친다. SCR은 요소수를 분해해 얻은 암모니아로 NOx를 질소와 물로 환원시키며, 디젤 엔진처럼 삼원촉매가 통하지 않는 희박 연소 조건에서 필수적인 역할을 한다. 디젤차의 후처리 시스템이 DOC·DPF·SCR을 순서대로 조합하는 이유는, 하나의 장치로는 디젤 연소 특성상 발생하는 여러 유해물질을 동시에 처리할 수 없기 때문이다. 이로써 연소에서 배출, 규제, 후처리까지 이어지는 내연기관의 연소·배기 흐름이 하나의 그림으로 완성된다.
