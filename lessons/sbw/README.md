# 조향감 · SBW

같은 차라도 "스포츠 모드"로 바꾸면 핸들이 묵직해지고, "컴포트 모드"에서는 가벼워지는 것을 경험해 본 적이 있을 것이다. 이것은 전동식 파워스티어링(EPS)의 모터 제어를 소프트웨어적으로 바꾸어 운전자가 느끼는 조향감(steering feel)을 조율한 결과다. 한 걸음 더 나가서, 최근 일부 차량은 핸들과 바퀴 사이의 기계적 연결(스티어링 샤프트)을 완전히 없애고 전기 신호로만 조향 명령을 전달하는 스티어-바이-와이어(SBW, Steer-by-Wire)를 채택하고 있다.

앞서 배운 EPS가 기계적 연결을 유지한 채 모터로 "힘을 보태는" 방식이었다면, SBW는 핸들 쪽 모듈과 바퀴 쪽 모듈이 전기적으로만 연결되어, 운전자가 느끼는 조향감 자체를 모터로 "인공적으로 만들어낸다". 이를 이해하려면 앞서 배운 제어 이론의 피드백 제어 개념이 필요하다.

## 학습 목표

- 조향감을 구성하는 요소(센터링 토크, 노면 반력, 댐핑)를 설명할 수 있다.
- EPS 기반 조향감 튜닝이 어시스트 맵과 댐핑 게인으로 어떻게 조절되는지 이해한다.
- SBW의 구조(핸들 액추에이터, 로드휠 액추에이터, 통신 네트워크)와 기계식 조향과의 차이를 설명할 수 있다.
- SBW가 요구하는 중복(redundancy) 설계와 안전 요건을 이해한다.

## 조향감과 그 튜닝

조향감이란 운전자가 핸들을 통해 느끼는 저항, 반력, 응답의 총체적 느낌을 말한다. 핵심 요소는 세 가지다. 첫째, 핸들을 중앙으로 되돌리려는 센터링 토크(centering torque, 복원력)로, 이것이 약하면 핸들이 "붕 뜬" 느낌을 주고 강하면 과하게 저항감이 든다. 둘째, 코너링 시 타이어가 노면에서 받는 횡력이 조향계를 통해 손으로 전달되는 노면 반력(road feedback)으로, 이 신호가 적절히 전달되어야 운전자가 그립 한계를 감지할 수 있다. 셋째, 핸들이 빠르게 움직일 때 발생하는 진동을 억제하는 댐핑(damping)이다.

EPS 차량에서는 이 세 요소를 모두 모터 제어 알고리즘으로 조율한다. 예를 들어 어시스트 맵의 기울기를 낮추면 조향이 더 무겁게(스포츠 지향으로) 느껴지고, 댐핑 게인을 높이면 핸들 복원 시 진동이 줄어 더 "차분한" 느낌을 준다. 일부 양산차는 운전자가 "컴포트/노멀/스포츠" 모드를 선택하면 ECU가 서로 다른 어시스트 맵과 댐핑 파라미터 세트를 불러와 조향감을 즉시 바꿔준다.

## 스티어-바이-와이어(SBW)의 구조

SBW는 조향감 튜닝을 극단까지 밀고 나간 결과라 할 수 있다. 핸들 쪽에는 조향각과 토크를 측정하는 센서와, 운전자에게 인공적인 반력을 만들어주는 "피드백 액추에이터(force feedback actuator)"가 있다. 바퀴 쪽에는 랙을 움직이는 "로드휠 액추에이터(road wheel actuator)"가 있으며, 두 모듈 사이에는 기계적 연결이 없고 전기 신호(통신 네트워크, 흔히 이중화된 CAN이나 FlexRay)로만 조향 명령이 전달된다.

이 구조의 장점은 명확하다. 조향비를 차속이나 주행 상황에 따라 자유롭게 바꿀 수 있고(가변 조향비), 핸들과 바퀴 사이 기계적 제약이 없어 자율주행이나 접이식 핸들 같은 설계 자유도가 커진다. 그러나 동시에 기계적 연결이 주던 "최후의 안전망"이 사라지므로, 센서와 액추에이터, 전원, 통신 경로를 모두 이중 또는 삼중으로 중복(redundancy) 설계해야 한다. 하나의 센서가 고장 나도 다른 경로로 즉시 전환되어야 하며, 이는 ISO 26262 같은 기능안전 표준에서 요구하는 엄격한 고장 대응 요건을 따른다. 피드백 액추에이터가 만들어내는 반력은 실제 타이어-노면 상호작용을 모델로 계산한 "가상의 조향감"이며, 이 모델이 얼마나 자연스러운지가 SBW 차량의 운전 느낌을 좌우한다.

## 정리

조향감은 센터링 토크, 노면 반력, 댐핑의 조합으로 느껴지며, EPS 차량에서는 어시스트 맵과 댐핑 게인 튜닝으로 이를 조율한다. SBW는 핸들과 바퀴 사이의 기계적 연결을 없애고 전기 신호와 피드백 액추에이터로 조향감을 인공적으로 재현하는 기술로, 가변 조향비와 설계 자유도라는 장점과 함께 고도의 중복 설계가 필요하다는 과제를 동반한다.
