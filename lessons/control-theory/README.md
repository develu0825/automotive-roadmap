# 제어이론 (PID · 상태공간)

고속도로에서 크루즈 컨트롤을 100 km/h로 맞춰 놓았다고 하자. 오르막길을 만나면 속도가 떨어지고, 내리막길에서는 올라간다. 차는 이 오차를 끊임없이 측정해서 가속 페달(혹은 스로틀)을 조절해 다시 100 km/h로 돌아오게 만든다. 이것이 피드백 제어(feedback control)의 기본 그림이다. 앞서 배운 디지털 신호처리로 깨끗해진 센서 신호와, 역학(dynamics-basics)에서 배운 시스템의 운동 방정식 위에서, 이번에는 "오차를 보고 어떻게 행동을 결정하는가"를 다룬다.

## 학습 목표

- 피드백 제어 루프의 기본 구조(목표값, 오차, 제어기, 구동기, 플랜트, 센서)를 설명할 수 있다.
- PID 제어기에서 P, I, D 각 항의 역할과 튜닝 시 발생하는 트레이드오프를 이해한다.
- 상태공간 표현이 무엇이고 전달함수 방식과 어떤 차이가 있는지 설명할 수 있다.
- 안정성이라는 개념이 제어 설계에서 왜 핵심인지 이해한다.

## 피드백 제어의 기본 구조

피드백 제어는 "목표값(reference) - 측정값(measurement) = 오차(error)"를 계속 계산하고, 그 오차를 줄이는 방향으로 제어 입력을 만드는 구조다. 크루즈 컨트롤이라면 목표값은 100 km/h, 측정값은 휠 스피드 센서가 알려주는 현재 속도, 오차가 있으면 제어기가 스로틀 각도를 조정한다. 이 루프가 초당 수십 ~ 수백 번 반복되면서 외부 교란(바람, 경사)에도 속도를 일정하게 유지한다.

## PID 제어기

PID는 비례(Proportional), 적분(Integral), 미분(Derivative) 세 항을 더해 제어 입력을 만든다.

$$u(t) = K_p e(t) + K_i \int_0^t e(\tau)\, d\tau + K_d \frac{de(t)}{dt}$$

- P항: 현재 오차에 비례해 반응한다. $K_p$가 크면 반응은 빠르지만 과도하면 진동(오버슈트)이 생긴다.
- I항: 오차를 누적해서 반응한다. 오르막길처럼 지속적인 오차(정상상태 오차)를 결국 0으로 없애주지만, 너무 크면 반응이 느려지고 심하면 발진할 수 있다.
- D항: 오차의 변화율을 보고 미리 반응한다. 진동을 억제하고 안정성을 높이지만, 센서 잡음에 민감해서 너무 크게 쓰면 떨림이 생긴다.

실무에서는 P, I, D 세 게인을 반복 실험으로 조정(튜닝)하는데, 지글러-니콜스(Ziegler-Nichols) 같은 경험적 방법이나 시뮬레이션 기반 최적화를 활용한다.

## 상태공간 표현

PID는 입출력 관계만 보는 단순한 방식이지만, 시스템이 여러 상태(속도, 가속도, 조향각 등)를 동시에 가질 때는 상태공간(state-space) 표현이 더 유용하다. 상태 벡터 $x$와 입력 $u$를 이용해 다음처럼 쓴다.

$$\dot{x} = Ax + Bu, \qquad y = Cx + Du$$

여기서 $A$는 시스템이 외부 입력 없이 어떻게 스스로 변화하는지를, $B$는 입력이 상태에 얼마나 영향을 주는지를 나타낸다. 이 표현의 장점은 여러 입출력을 가진 복잡한 시스템(예: 차량의 횡방향·요(yaw) 동역학)도 하나의 수식 체계로 다룰 수 있다는 점이다. 상태공간에서는 상태 피드백 $u = -Kx$ 형태의 제어기를 설계해 시스템의 고유 응답 특성(극점)을 원하는 위치로 옮길 수 있는데, 이를 극점 배치(pole placement)라 한다.

## 안정성이라는 기준

어떤 제어기를 설계하든 가장 먼저 확인해야 할 것은 안정성이다. 안정한 시스템은 작은 교란이 들어와도 시간이 지나면 원래 상태로 돌아오지만, 불안정하면 오차가 계속 커져 발진하거나 폭주한다. 전달함수 관점에서는 극점이 모두 안정 영역(연속시간이면 좌반면)에 있어야 하고, 상태공간 관점에서는 $A - BK$ 행렬의 고유값이 안정 조건을 만족해야 한다. 안정성 판정은 루스-후르비츠(Routh-Hurwitz) 기준이나 고유값 계산으로 확인한다.

## 정리

제어이론은 목표와 측정값의 오차를 줄여 시스템을 원하는 상태로 수렴시키는 방법을 다룬다. PID 제어기는 비례·적분·미분 세 항의 조합으로 단순하면서도 강력하게 동작하고, 상태공간 표현은 여러 상태를 가진 복잡한 시스템을 체계적으로 다루며 극점 배치 같은 설계 기법을 제공한다. 어떤 방식이든 안정성 확보가 전제 조건이며, 이는 다음 단계인 상태추정에서 측정값과 모델을 결합할 때도 계속 중요하게 쓰인다.
