# 확률 · 통계

같은 속도로 달리는 차의 속도 센서를 10번 측정해도 정확히 같은 값이 나오지 않는다. 60.0 km/h, 60.3 km/h, 59.7 km/h처럼 매번 조금씩 다른 값이 찍힌다. 이것을 "센서가 고장 났다"고 단정할 수는 없다. 모든 센서에는 노이즈(noise)라는 작은 무작위 오차가 섞여 있기 때문이다. 확률과 통계는 이런 불확실한 값들을 "대충 무시"하지 않고, 평균이 얼마인지, 오차가 어느 범위에서 얼마나 자주 나타나는지를 수치로 다루는 도구다.

앞서 배운 미적분 · 벡터가 "정확한 값"을 다루는 언어였다면, 확률 · 통계는 "불확실한 값"을 다루는 언어다. 두 도구는 서로 보완적이며, 이후 신호 · 센서 레슨에서 센서 데이터를 걸러내는(필터링) 방법을 배울 때 이 레슨의 개념이 바로 쓰인다.

## 학습 목표

- 확률 변수와 확률분포(특히 정규분포)의 의미를 설명할 수 있다.
- 평균(mean)과 표준편차(standard deviation)로 데이터의 중심과 흩어짐을 요약할 수 있다.
- 센서 측정값을 반복 측정 데이터의 관점에서 해석하고 오차 범위를 추정할 수 있다.
- 신뢰도(reliability)와 오차의 누적이 시스템 설계에 왜 중요한지 이해한다.

## 확률분포와 정규분포

확률분포는 "어떤 값이 얼마나 자주 나오는가"를 함수로 나타낸 것이다. 센서 노이즈처럼 평균 주변에 몰리고 양쪽으로 갈수록 드물게 나타나는 데이터는 흔히 정규분포(normal distribution, 가우시안 분포)로 근사한다. 정규분포는 평균 $\mu$와 표준편차 $\sigma$ 두 숫자만으로 전체 모양이 결정된다.

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

실용적으로 기억할 값은 "68 ~ 95 ~ 99.7 규칙"이다. 측정값의 약 68%는 $\mu \pm \sigma$ 안에, 약 95%는 $\mu \pm 2\sigma$ 안에, 약 99.7%는 $\mu \pm 3\sigma$ 안에 들어온다. 예를 들어 속도 센서의 평균 오차가 0이고 표준편차 $\sigma = 0.3$ km/h라면, 측정값의 95%는 실제 속도에서 ±0.6 km/h 범위 안에 있다고 기대할 수 있다.

## 평균과 표준편차로 데이터 요약하기

실제 차량 테스트에서 같은 조건으로 10번 측정한 제동 거리가 20.1, 20.4, 19.8, 20.2, 20.5, 19.9, 20.3, 20.0, 20.1, 19.8 m였다고 하자. 평균은 각 값을 더해 10으로 나눈 값으로, 약 20.1 m가 된다. 표준편차는 각 측정값이 평균에서 얼마나 떨어져 있는지를 나타내는 지표로, 분산(각 오차의 제곱의 평균)의 제곱근으로 계산한다.

$$\sigma = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2}$$

이 예시에서는 표준편차가 약 0.25 m 정도로 작게 나오는데, 이는 측정이 꽤 일관적이라는 뜻이다. 반대로 표준편차가 크면 같은 조건에서도 결과가 들쭉날쭉하다는 신호이므로, 테스트 방법이나 센서 자체를 점검해야 한다.

## 센서 오차와 신뢰도

자동차에는 속도, 가속도, 조향각, 타이어 압력 등을 재는 수십 개의 센서가 들어간다. 각 센서는 제조 편차, 온도 변화, 전자 노이즈 때문에 항상 약간의 오차를 갖는다. 이 오차를 하나의 고정된 숫자로 생각하기보다, "평균 오차(bias)"와 "흩어짐(표준편차)"으로 나눠 생각하면 설계에 유용하다. 예를 들어 평균 오차가 0에 가깝고 표준편차만 있는 센서는 여러 번 측정해 평균을 내면 참값에 가까워지지만, 평균 오차 자체가 크게 치우친(bias가 큰) 센서는 아무리 평균을 내도 오차가 사라지지 않는다.

신뢰도 설계에서는 여러 독립적인 오차 요인이 더해질 때 분산이 각각 더해진다는 성질도 중요하다. 즉 센서 오차, 신호 전달 지연, 계산 오차가 섞이면 전체 불확실성은 각 요인의 분산을 합한 뒤 제곱근을 취한 값이 되며, 이는 왜 하나의 센서만 믿지 않고 여러 센서를 결합(센서 퓨전)하는지에 대한 통계적 근거가 된다.

## 정리

확률분포, 특히 정규분포는 센서 측정값처럼 불확실한 데이터를 체계적으로 표현하는 틀이다. 평균은 데이터의 중심값을, 표준편차는 흩어짐의 정도를 요약하며, 이 둘로 측정값이 어느 범위에 들어올지를 확률적으로 추정할 수 있다. 이러한 오차 분석은 센서를 평가하고 여러 센서를 결합해 신뢰도를 높이는 모든 설계의 출발점이 된다.
